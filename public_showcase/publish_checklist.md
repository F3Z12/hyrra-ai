# Publishing Checklist

Use this checklist when you are ready to publish the Hyrra AI Showcase repository.

- [ ] **Create Public Repo**: Create a new, empty public repository on GitHub called `hyrra-ai-showcase`.
- [ ] **Clone Public Repo**: Clone the empty repository to a clean directory on your local machine.
- [ ] **Copy Safe Assets**: Copy the contents of this `public_showcase/` folder into the root of your newly cloned repository. (Rename the `README.md` to be the primary README).
- [ ] **Add Media**: Create an `assets/` folder in the new repository. Add sanitized, high-quality screenshots or screen recordings of the dashboard, match results, and Kanban board.
- [ ] **Link Demo**: Add a link to a Loom or YouTube walkthrough video in the README.
- [ ] **Verify No Code Leak**: Triple-check that no `.ts`, `.py`, `.json`, or configuration files were accidentally copied from the private source code into the public repository.
- [ ] **Sanitize Screenshots**: Ensure your screenshots do not accidentally display your personal API keys, private email addresses, or real contact info.
- [ ] **Push**: Commit the changes and push the showcase repository to GitHub.
